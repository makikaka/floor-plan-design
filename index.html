How the config works
  • wall: thickness between rooms (cm). Gaps between rooms are drawn as wall.
  • rooms: x, y = top-left interior corner, w = width (left–right), h = depth (top–bottom). Move a room by changing x/y. Set "outdoor": true for terraces. Give several rooms the same "group" text to make them one room (e.g. an L-shape); their areas are added together. An opening with "swing": "none" removes part of the wall between them – the rest stays as a short wall.
  • doors: room = id of the room it belongs to, wall = N / E / S / W, offset = distance from the wall's start (N/S walls: from the left corner; E/W walls: from the top corner) to the start of the opening, width = opening width, swing = "in" (opens into that room), "out" (opens away from it) or "none" (open passage), hinge = "start" or "end" (which end of the opening the hinges are on).
  • windows: same as doors but without swing/hinge.
  • N is the top of the drawing, E right, S bottom, W left.
